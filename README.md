# Local AI Boost Club Team Vault

해커톤 팀원과 로컬 에이전트가 같은 목표·작업·결정·근거·인수인계를 공유하는 협업 Vault입니다.

## 시작 순서

1. `AGENTS.md` 읽기
2. `00-dashboard/current-status.md` 읽기
3. `03-tasks/task-board.md` 확인
4. `02-decisions/decision-log.md` 확인
5. 작업 등록 후 실행
6. 실제 결과와 검증 근거 기록
7. 세션 종료 전 `06-handoffs/agent-handoff-template.md` 작성

## 원칙

- 개인 정보와 비밀값을 저장하지 않습니다.
- 사실·해석·제안을 분리합니다.
- 실행 근거 없는 완료 선언을 하지 않습니다.
- 팀의 기준본은 이 Vault의 파일과 Git 이력입니다.
