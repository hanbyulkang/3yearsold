# 미니게임 허브 썸네일 — 이미지 생성 프롬프트

C-01 미니게임 허브에 **정사각형 게임 프로필**로 들어갈 2장.

- 규격: **1:1 정사각형**, 1024×1024 이상
- 나란히 놓이므로 **두 장이 한 세트로 보여야 한다** — 아래 "공통 규칙"을 두 프롬프트 모두에 넣을 것
- 실제 게임 팔레트에서 뽑은 색이므로 **HEX를 그대로 지정**한다

---

## 공통 규칙 (두 프롬프트에 모두 포함)

```
스타일: 플랫 벡터 일러스트, 굵은 라운드 코너, 부드러운 그림자.
질감·그라디언트 과용 금지. 3D 렌더링·사실적 묘사 금지.
아이소메트릭 도트 느낌의 정돈된 게임 아이콘.

구도: 정사각형 1:1. 중앙에 주요 오브젝트를 크게.
가장자리 8% 는 여백으로 비워둘 것 — 앱에서 라운드 마스크가 씌워진다.
텍스트·숫자·로고를 넣지 말 것. 글자 없이 그림만.

톤: 밝고 따뜻하며 귀엽다. 어둡거나 무섭지 않게.
동물을 불쌍하게 그리지 말 것 — 건강하고 밝은 모습.
```

> **글자 금지**가 중요하다. 이미지 생성 모델은 한글을 거의 항상 깨뜨리고,
> 게임 이름은 어차피 앱 UI에서 텍스트로 얹는다.

## 1. 3매치 퍼즐 (MG1)

```
정사각형 1:1 게임 아이콘. 강아지 간식 3매치 퍼즐 게임의 썸네일.

내용:
크림색 배경 위에 둥근 모서리의 퍼즐 보드 격자(3×3 정도만 보이게, 살짝 기울인
각도). 격자 칸마다 파스텔 톤의 둥근 타일이 있고, 타일 위에는 강아지 간식
아이콘이 하나씩 — 뼈다귀, 발바닥 자국, 육포 조각, 동그란 사료 알갱이.
가운데 가로줄의 뼈다귀 타일 3개가 반짝이며 매치되는 순간을 표현
(작은 별빛·스파클 이펙트, 타일이 살짝 커진 상태).

색상 (반드시 이 팔레트):
- 배경 크림 #FAF3E6
- 강조 골드 #F2B34C
- 포인트 주황빛 레드 #E45B4F
- 선·그림자 브라운 #4A3327
- 보조 브라운 #6A583F

분위기: 따뜻하고 아늑한, 손에 잡히는 보드게임 같은 느낌.
```

## 2. 2048 퍼즐 (MG2)

```
정사각형 1:1 게임 아이콘. 숫자 합치기(2048 방식) 퍼즐 게임의 썸네일.

내용:
짙은 남색 보드 위에 4×4 격자(살짝 기울인 각도). 칸에 둥근 사각 타일들이
놓여 있고, 타일에는 숫자 대신 강아지 아이템 아이콘이 단계별로 그려져 있다 —
작은 타일은 발바닥 자국, 중간 타일은 뼈다귀, 큰 타일은 육포,
가장 큰 타일 하나에는 귀여운 강아지 얼굴.
타일 두 개가 합쳐지며 강아지 얼굴 타일이 되는 순간을 표현
(합쳐지는 빛 번짐, 살짝 튀어오른 타일).

색상 (반드시 이 팔레트):
- 보드 남색 #313962
- 배경 크림 #FFF8ED
- 낮은 단계 타일 베이지 #EEE7DA → #EFE1C4
- 중간 단계 타일 주황 #F5B464 → #F18B52 → #EC694B
- 높은 단계 타일 보라 #9D5CB5 → 남보라 #5A6DBE
- 선·글자색 잉크 #2A304D

분위기: 차분하고 세련된, 숫자 퍼즐 특유의 정돈된 느낌.
```

## 두 장을 받은 뒤 확인할 것

1. **나란히 놓고 본다.** 한 세트로 보이는가, 아니면 따로 노는가
   — MG1은 따뜻한 크림, MG2는 차가운 남색이라 대비는 의도된 것이다.
   다만 라운드 처리·아이콘 굵기·그림자 강도는 같아야 한다.
2. **작게 줄여본다.** 허브에서는 한 변 200px 안쪽으로 들어간다.
   그 크기에서 뭘 하는 게임인지 읽히지 않으면 다시 뽑는다.
3. **글자가 섞여 들어왔는지** 확인한다. 들어왔으면 "no text" 를 강조해 재생성.
4. 강아지가 마르거나 슬퍼 보이면 다시 뽑는다 (PRD §1.2 — 동물을 불쌍하게 그리지 않는다).
