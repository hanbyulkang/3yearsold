## 1. `sample-national-rescue-dogs.json`

| 항목 | 내용 |
|---|---|
| 원본 입력 | 국가동물보호정보시스템 구조동물 조회 API 응답 원문 |
| 정제 | `response.body.items.item` 배열만 추출. 필드 값은 미변형 |
| 건수 | 20건 (전체 공고중 1,344건 중 앞 20건, `upkind=417000&state=notice`) |
| 라벨 | 없음 (원본 그대로) |
| 개인정보 | **제거 불필요 — 개인정보 없음.** 보호소 담당자명(`careOwnerNm`)은 "창원시장", "밀양시청" 등 직위·기관명이나 일부는 개인 성명(예: "민성식")이 들어감 → **화면 노출 금지** |
| 공개 범위 | 공공데이터포털 개방 데이터 |

### 품질 문제
- `age`가 `2026(60일미만)(년생)` 형태 — 단순 정규식 파싱 시 깨짐
- `weight`가 `7(Kg)` 문자열
- 이미지 파일명에 대괄호 `...297[1].jpg` (20건 중 3건) → URL 인코딩 필수
- 이미지가 HTTP → 프록시 필요
- `healthChk` / `vaccinationChk`는 일부 레코드에만 존재 → optional 처리
- **같은 `specialMark`가 9건 중복** — 한배 새끼라 설명이 동일. 카드 목록에 그대로 뿌리면 도배됨

### 특기 사항 — 가족 관계
20건 중 10건이 창원 단감농장(`happenPlace` 동일, `happenDt` 동일) 출신이다.
- 어미 1마리: `448567202601055` — "자견 9두와 함께 입소, 좌후지 발톱 빠져서 출혈-응급처치"
- 새끼 9마리: "26년 7월 7일생 추정, 이빨 안남, 모견+남매들과 함께 입소, 모유 수유 중", 0.6~1.3kg

`happenPlace` + `happenDt`로 가족을 묶을 수 있다는 **가설의 근거 사례**다. 전국 유효성은 미검증.

## 2. `sample-seoul-shelter-pets.json`

| 항목 | 내용 |
|---|---|
| 원본 입력 | 서울 열린데이터광장 `vPetInfo` 응답 원문 |
| 정제 | `vPetInfo.row` 배열만 추출. 필드 값은 미변형 |
| 건수 | **24건 전량** (개 15 · 고양이 9) |
| 라벨 | 없음. `CONT` 안의 `[성격]` 섹션이 사실상 사람이 작성한 라벨 역할 |
| 개인정보 | **제거 불필요 — 개인정보 없음.** 동물 이름·보호소 유선번호(대표번호)만 포함 |
| 공개 범위 | 서울 열린데이터광장 개방 데이터 |

### 품질 문제
- `CONT`가 **HTML 원문** (`<p>`, `<strong>`, `&bull;`, `\r\n` 혼재)
- 템플릿이 2종 — 단문(~1,850자) / 장문(~6,000자)
- 섹션 마커가 `[성격]`과 `○ 성격`으로 뒤섞임 → **정규식 파싱 불가, LLM 파싱 필요**
- `ANIMAL_SEX`가 국가 API와 다름: **`W`(암컷) / `M`(수컷)** ← 국가 API는 `F` / `M`
- `MOVIE_URL`은 24건 중 10건만 존재
- `ADOPT_STATUS`에 `미표출` 값이 있음 → 노출 필터 필요

### 상태값 분포
`ADOPT_STATUS`: 입양문의가능 11 · 입양진행중 6 · 신청마감 4 · 입양완료 1 · 미표출 1 (개+고양이 합)
`FOSTER_STATUS`: `임시보호가능` — PRD 참여 퍼널의 임보 단계와 직접 연결

## 3. 두 소스를 같이 쓸 때 주의

| 항목 | 국가 API | 서울 vPetInfo |
|---|---|---|
| 성별 코드 | `F` / `M` / `Q` | **`W`** / `M` |
| 나이 | `age` 문자열 "2019(년생)" | `ANIMAL_BRITH_YMD` "2021-01-11" |
| 체중 | `weight` "7(Kg)" | `WEIGHT_KG` "5.25" |
| 식별자 | `desertionNo` | `SEQ` |

**정규화 레이어 없이 두 소스를 한 화면에 섞으면 성별이 뒤집힙니다.** 공통 도메인 모델로 변환 후 사용할 것.
